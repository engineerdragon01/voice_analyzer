# Predictions for the provided calls

Generated by the final configuration (hybrid DSP + Gemini 3.5 Flash-Lite, prompt v2, adaptive samples) with:

```bash
python cli.py data/provided -o predictions/provided_calls
```

| File | Contents |
|---|---|
| `provided_calls.csv` | `name, result_json, error`, the manifest format required by the spec |
| `provided_calls.json` | the same rows as JSON |
| `provided_calls.meta.json` | per file: duration, timings, token usage, cost, samples used, DSP measurements (model evidence text removed, since it quotes callers) |
